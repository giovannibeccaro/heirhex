# test/

Test automatici con GUT (Godot Unit Test). La struttura è lo **specchio di `core/`**: `core/combattimento/x.gd` → `test/combattimento/test_x.gd`.

- I file di test si chiamano `test_*.gd` ed estendono `GutTest`.
- `fixtures/` contiene dati minimi scritti per i test (non dipendono dall'esportazione).

Comando per eseguirli: vedi `docs/COMANDI.md`.
